# Adya Tirvir Portfolio Website

This ZIP contains the complete static website source.

## Files

- `index.html` — page structure and portfolio content
- `styles.css` — design, responsive layout, animations, rain and lightning styling
- `script.js` — interactions, atmosphere modes, navigation and Sudoku interface
- `sudoku-engine.js` — random medium Sudoku generation and solution checking
- `assets/` — website artwork
- `favicon.svg` — browser tab icon

## Open locally

Open `index.html` in a browser. For the most reliable preview while editing, open the folder with Visual Studio Code and use the Live Server extension.

## Publish with GitHub Pages

Upload the contents of this folder to the root of a GitHub repository, then enable GitHub Pages for the repository's main branch.

No build command or package installation is required.
